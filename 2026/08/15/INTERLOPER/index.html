INTERLOPER / PROJECT SKYBOX

ARG 完整整理
2026-08-12 · ARG 解析

一个以 Source 引擎本身为舞台 的ARG。它的"超自然现象"不是发生在游戏剧情里，而是发生在引擎的 demo 录制、地图编译、模型加载这些底层机制中。整个谜团围绕一个核心命题展开：Source 引擎的"虚空（Void）"一直在静默地记录和存储所有玩家的记忆，而一个名为 FSKY 的挪威服务器提供商（最早可追溯到 2005 年）似乎建立了一套通过 Source 引擎介质来通信的服务器系统。

一、核心机制：INTERLOPE 命令与"虚空"

整个 ARG 的技术根基是一条被称为 INTERLOPE Command 的隐藏命令。它本质上是一个被某个未知作者埋入 Source 引擎的后门（backdoor）/ 漏洞（exploit）——没人知道它是怎么被创建、如何运作的，只知道它很可能并非虚空建造者的本意，因此常被调查者称为"漏洞"。

INTERLOPE 命令

  • 触发条件：《半条命2》d1_town_01 地图（"We Don't Go to Ravenholm" 章节第一关）某条通常空着的小巷里，会零星出现一个被修改过的 "Umbrella Man" 涂鸦（decal_graffiti038b）。涂鸦出现的时间窗口极短，每次仅持续数小时。它的出现标志着 INTERLOPE 命令激活，此时多数 Source 引擎游戏可以反复拉取 demo，直到涂鸦消失、命令再次关闭。
  • 作用机制：这条命令相当于"虚空"的后门，从虚空中"拉取" demo。但拉取是有代价的——拉取 demo 似乎会让虚空内的核心实体 INTERLOPER 停止移动，直到该 demo 录制完毕。换言之，每次"偷看"都会短暂定格被观察的对象。
  • 生成的 demo 有分类（Type 1–Type 7），其中 Type 5 是最具代表性的"完整实体 + 环境交互" demo（如 cstrike、fortress、spookycoast、misty、helmetcreek 等）。
  • Ordinance 调查后：涂鸦纹理被替换，INTERLOPE 命令开始专门产生 Type 7 demo，类型多样性从此丧失。

Eida 的两种早期进入方式（不同于社区的 Portal RTX 路线）

在 Anomidae 之前，Eida Machinima 已独立摸索出两条进入虚空的路径，但都语焉不详：

  1. 耗时数天的生成法：Eida 能以某种方式让 demo 连续生成一整夜甚至数天。这几乎不可能是靠涂鸦触发的（涂鸦一次只出现几小时），所以他多半有绕过涂鸦的私有方法。他在视频结尾曾留下线索：让观众连接一个如今已失效的 IP 地址并参考前两集（已丢失）的指令——因此这套方法至今成谜。
  2. Hammer 强制指定地图法：Eida 还找到了一种强制在 Hammer Editor 自制地图上生成 demo 的手段，用于测试他捕获到的某个实体。这套流程产出了著名的 longtrap demo——展示了该实体从 Eida 的自制地图，穿越虚空，抵达《半条命2》早期泄密版中的 hazflick 地图的全过程。

虚空（The Void）

又称 Source Void / Demo Void / FSKY Void，是一个跨越未知长宽高的巨大空间：

特性 说明
记忆存储 能够记录和存储"记忆（memories）"——即玩家在各种 Source 引擎游戏中的事件
跨游戏链接 与几乎所有 Source 引擎游戏实例兼容并链接，穿越虚空可以实现游戏实例间的直接连接
地图尺寸突破 正常 Source 地图最大 32,768 立方 hammer 单位，但链接到虚空的游戏实例允许远超此边界的几何
核心实体 虚空内有一个不断移动的实体叫 INTERLOPER，其起源未知。SourceBox 程序的 tracker 功能跟着它走，记录文件为 INTERLOPE.dme
背景音轨 多种虚空探索过程中会持续播放 drone2lp.wav 这一音轨

int_menu 的"回放镜像"机制（第二次进入方式）

Portal Incident 之后，Anomidae 发现 Portal with RTX 处于损坏状态时反而不崩溃。连接该客户端会加载一张名为 int_menu 的地图——一片巨大的、黑白棋盘格地板的空旷空间（这一棋盘格母题反复出现在所有与虚空相关的地图中）。

关键机制在于：

  • 在 int_menu 上可以录制 demo，但无法回放；
  • 然而，当把这段 demo 放到另一个 Source 引擎客户端里去播放时，Portal RTX 客户端会在虚空里无纹理地"重演" demo 中的动作——相当于把 demo 变成了观察虚空的"镜子"。
  • 用 spectate 指令离开地图边界，即可从这个镜面窗口直接走入虚空。这条路径在 INTERLOPER 7 中通过 Void Probes 进一步精炼，并配合专门程序从发现的站点提取资源，构成了第一、二次远征的技术基础。

这种探索方式有明显局限：发现新东西极慢、多数尝试以崩溃告终；且会吸引 VRAD-OR 实体（见实体图鉴），它们碰撞客户端即触发崩溃。Portal RTX 视角本身也无纹理、视野极短。

SourceBox 立方体的完整能力清单（最终进入方式）

SourceBox 程序会在任何已连接的 Source 引擎客户端中（自动或手动）生成一个内部纹理缺失的小白立方体。它的能力远不止"占位"：

能力 说明
Tracker 生成 在客户端中生成 INTERLOPER 的追踪记录 INTERLOPE.dme
伤害激活 立方体可被特定伤害源"激活"——包括物理反应、Counter-Strike: Source 的 A.W.P. 狙击枪、Garry's Mod 插件 GBOMBS 的氢弹
Cube Capture（立方体捕获） 当立方体在被损坏的 Xbox 模拟器客户端中被激活时，立方体和其周围区域会被传送到模拟器内的虚空中
Spray 入水访问记忆 把立方体放入水中，配合 Source 引擎的 spray 系统，可前往虚空中特定的记忆（详见第六节）
Aimbot 跨虚空锁敌 内置 aimbot 功能，能锁定其他玩家或立方体，即便目标身在虚空之中

Anomidae 正是趁 INTERLOPER 卡在拉取 demo 的瞬间，在它附近激活了一个立方体，把 INTERLOPER 本身、以及当时所在的早期版 Kleiner 实验室地图一并"捕获"进了模拟器客户端——从而再次把所有 Source 客户端通过虚空互相连通。他以筹划"第五次也是最后一次远征"为幌子，用这套流程试图让虚空变得不可访问，并最终以此终结了 INTERLOPER 调查。

进入虚空的演化路径

INTERLOPE 命令（涂鸦触发）── Eida 的私有 IP 法 / Hammer 强制法（早期，已失传）
    ↓
Portal RTX 的 int_menu（Portal Incident 后）→ 回放镜像 + Void Probes
    ↓
Skyghost 事件（Tuesday Incident 后）→ F11 全客户端无画面互联
    ↓
Ordinance 地图控制（社区调查）→ view.vtf 渲染
    ↓
SourceBox 立方体捕获（最终手段）→ Cube Capture + spray 入水

二、FSKY：谜团的源头组织

FSKY 是一家基于挪威的 Source 游戏服务器托管商，已知早在 2005 年就已存在。其论坛广告自称拥有"喜爱的游戏与模组"、"沉浸式世界"，是"游戏娱乐的未来"。

FSKY 留下的关键痕迹

  1. fortress demo：在 RED 基地阳台用 brush 拼出 "FSKY" 字样，靠近会触发 demo 录制；在 Hammer 中查看这些字母，其名称为 "fuckyou"
  2. Tuesday Manifest 中的 data86：在 Team Fortress 2 demo 生成的地图的 3D 天空盒深处隐藏着 "FSKY"
  3. DM Editor 关联：DMNPC 的命名规范暗示它们与 DM Editor 和 FSKY 有关联
  4. Valve 关联：FSKY 似乎与 Valve 有联系——makeface demo 使用了 Source 引擎开发期间的缺失纹理并带有 VHS 画质，暗示其来自《半条命2》开发时期
  5. cge7-193 服务器：社区发现的 FSKY 相关服务器，成为后续 ORDINANCE 等地图调查的入口

Anomidae 在 INTERLOPER 9 中总结：这个谜团的起源毫无疑问指向一系列连接到 FSKY 的服务器，这些服务器使用 Source 引擎作为介质来传递特殊信息，并且它们为了某个"某人"而存在。

三、主要实体图鉴

🌑Umbrella Men（伞人）

  • 采用 G-Man 模型重度修改而成，几乎被染成黑色，眼睛和西装领口完全透明
  • 存在多个个体，出现在 spookycoast、misty 等 demo 中
  • 观察玩家或攻击 DMNPC，动机不明

🤖DMNPC

全称来自 Anomidae 保存的 Type 5 demo（cstrike 和 fortress）。在 cstrike 中我们视角的模型在 Hammer Editor 中名为 dmnpc_capture_pawn，模型名 ent_dmnpc_tleet。

特征：

  • 拥有全身运动与环境交互能力（捡罐头、用枪射击、指向兴趣点、double take）
  • 似乎被 hint node（提示节点） 吸引
  • 可以被杀死（demo 中会听到奇怪的溺水音效）
  • 在 spookycoast 中出现过一个发白光的 DMNPC（"White Eyes"），行为具有敌意

💥Crasher

出现在各类 Source 游戏中的实体，最可能在输入 INTERLOPE 命令后触发。

能力：

  • 无碰撞穿越（noclip）
  • 切换模型
  • 直接攻击玩家导致游戏崩溃

Eida Machinima 的《Weird Crash on TF2》记录了其实体证据。社区推测它们可能由玩家控制，或与 Umbrella Man 有关。

👁Office Heads

仅在 Tuesday Manifest 的 data43（CS:GO demo，"officehead"）中出现。

特征 详情
外观 巨大的黑色头部，眼睛和嘴部有极亮的玩家纹理，看起来像发光
内部名称 ent_undef
音效 移动时播放钟琴音效，越靠近越响
行为 发现玩家后加速、张开嘴眼、播放 "hello" 音效，然后冲向 DMNPC 播放怪异音乐
关联 与 White Eyes、Umbrella Man 有相似特征

🌸Mona / Olive

Eida Machinima 第八次调查期间捕获的实体。

  • 最初通过推字母拼出 "MONA" 而得名
  • 但在《Correcting the record》中暗示其真名可能是 Olive
  • Eida 通过伤害它来"激活"它
  • 最终在《I'm Done. Goodbye.》中将其删除
  • 名字 "Mona" 也出现在 Eida 2007 年的《Garrysmod Zombie Slayer》中——一个叫 Mona 的女性市民角色

👻Skyghost

Tuesday Manifest 生成期间，projectskybox.exe 运行时捕获的实体，PROJECT SKYBOX 称其为 skyghost。

  • 在后续的 INTERLOPER A–F 中被持续研究
  • 表现出生成模型、传送、"被动循环（passive cycle）"等行为
  • 最终在 INTERLOPER F 中被 Anomidae 用 FLASHLIGHT NUKE 攻击，彻底切断了与服务器的连接

😇Angel（天使）

Anomidae 在虚空坠落中避开了扭曲的 Umbrella Man 后，在一个神秘复合体中发现的巨大挣扎的人形实体。

  • 与其他 Umbrella Man 相似，但没有拿伞，而是戴着宽檐太阳帽（纹理缺失）
  • 不具敌意，甚至引导 Anomidae 看到了一张名为 Axlvote 的地图
  • 社区给它起了 "Angel" 这个流行的名字

⚙️VRAD-OR

只存在于 Demo Void 中的奇异实体，没有关联模型。

  • 接触玩家后会激活 VRAD（Valve 官方的光照计算工具）
  • 但执行的是修改版 VRAD——从未知来源获取光照数据，生成到 c:/users/jan/desktop/new folder/v_test.bsp，随后游戏崩溃
  • 首次出现在 INTERLOPER 7 中 cp_steel 外 Demo Void 里的一个盒子中

🟦Ordinance Entities

Ordinance 渲染中发现的多种实体，行为各异，使用 Source 引擎的各种模型。

🟫Combine Elite 控制的实体

Ordinance 调查期间反复出现的实体，栖居在 INTERLOPER 7 创建的 Void Probe 中，会生成并控制玩家 pawn。在 INTERLOPER F 中，它们被从 Point of Interest 创建并送入 Source Void，为未知目的寻找并最终销毁记忆。

五、SPISE 代码系统：密码学收束

SPISE 是 Eida 在 2014 年实验的系统（Spise Test 系列视频），也是 ARG 后期的密码学核心。值得注意的是，Eida 当年的 Spise 系统很可能就是 SourceBox 的早期版本或平行版本——两者都用立方体观察虚空，并用相似的伤害触发器激活。

解密步骤

第一步：确定密钥

"11 acts" 作为密钥，对应十六进制的 EDCA?B

第二步：确定合法代码的数量和长度

INTERLOPER B 中的 FOURX6 暗示：

  • 合法代码数量 = 4 个
  • 每个代码长度 = 6 个字符

第三步：收集代码

来自 INTERLOPER E 片尾字幕中无 Discord 用户名的贡献者首字母：

Immitator, Ulmer, Povvelsk [lucy], 2hat2kills, 99ants, Yyvonnix, Super Gaming Bug

加上 UP29YS 作为额外代码。

第四步：按密钥顺序拼接

按密钥 EDCA?B 的顺序，从 E、D、C、A 各集收集代码，每次从每集取一个字符，形成最终代码：

UCVlPY Ko2tsn 9ibfYY nKSnmw

合并得到最终代码：

UCVlPYKo2tsn9ibfYYnKSnmw

第五步：指向目标

这个代码直接指向一个 YouTube 频道：SILLY CONE FINDER

六、虚空探索的关键发现

6.1 各次远征发现的站点

前两次远征所见的站点统称为 Void Sites（虚空站点）——是各种未知的地图几何碎片。由于 int_menu 探索的局限，这些地图最初都以极短视野、无纹理的状态被看见；直到第二次远征用针孔相机收集 VRAD-OR 实体生成的光照信息，才揭示它们确实有完整的纹理和光照。

第二次远征（Void Probes + 数据提取）

使用 Void Probes 并从 demo 中提取游戏数据，以有限视野观察站点。重要发现：

  • Box Structure（盒子结构）：一片平坦平台加一个浮空盒子。盒子内地板上有一个方形小凹槽，浮空字母拼出 "HᒐEM"。诡异的是——提取资源时字母似乎漂在墙边，但"亲自"重返现场时，字母却是平行于地板悬浮的。Eida 的视频《Mona Doesn't Move Anymore》里出现过一个外观相似的房间。
  • 追踪 Crasher 轨迹：沿 Eida 视频中 Crasher 的移动轨迹，找到了 Box Structure 所在的站点。
  • 针孔相机采光：用 VRAD-OR 实体生成的光照信息拼出有限但真实的纹理画面。
  • Anomidae 用 SourceBox 的 spray 交互做的首次成功测试：一张纯黑底红色圆圈的图片——SourceBox 把他送进一张看似空荡的地图，里面只有一个带红色棋盘格图案的浮空小球，远处似乎有光，但未被进一步调查。

第三次远征中的关键插曲——"spave"事件：某刻地图的暗雾变亮，一个以 T 姿势站立的 Human Commando 模型出现——它来自 TF2 发售前《Invasion》版本，手持 Half-Life 2 早期的重力枪。不清楚它是玩家、实体，还是过去某位玩家的记忆残影。它用重力枪抓起 Anomidae，问他是不是玩家，反复念叨 "spave" 数次，最后把他扔出地图边界，明确命令他离开。

第四次远征（Ordinance）

社区通过 cge7-193 服务器发现的 Ordinance 地图允许控制一个实体穿越虚空，命令结果被"渲染"到 view.vtf。这也是最终向 Skyghost 发起 FLASHLIGHT NUKE 总攻的舞台。

6.2 Point of Interest

  • 基于 d2_coast_07（与 Type 5 demo spookycoast 同张地图）
  • 包含巨型道具漩涡、多个 DMNPC、一个制造 Void Probe 的大型实体
  • 这些探针被源源不断送出，在虚空中寻找并最终摧毁 Anomidae 的记忆站点
  • Skyghost 在 INTERLOPER C 之后驻扎于此
  • 最终被 Anomidae 用 FLASHLIGHT NUKE 多次攻击彻底摧毁，Point of Interest 内的一切（包括 Skyghost）灰飞烟灭

6.3 虚空底部

这是虚空中已知最低点：

  • 一片广阔无垠的棋盘格地板（与 int_menu 同款纹理），Anomidae 在 INTERLOPER C 中走了数小时仍未触及任何边缘
  • 背景播放 citadel_drone_loop2.wav（出自 Half-Life 2）
  • 发光门道：类似 Portal RTX 客户端中见过的那种。它最初呈现为女性上半身的形态（与 Eida Spise Tests 中某个形象相似），头顶巨大灰色圆锥体，周围环绕多个纹理缺失的球体。用 Skyghost/撬棍"使用"它后，它才变成门道形状
  • Anomidae 走过门道 → projectskybox.exe 崩溃 → 生成 Kulcs 地图
  • 坠落道具现象：SourceBox 直播中，tracker 程序里能看到若干灰色球体带 X/Y/Z 指示器的实体，其中一些持续向下坠落——很可能就是正在落向底部途中的道具
  • Anomidae 的 Xbox 模拟器客户端也曾卡在一张类似的空间里：棋盘格地板、门道，外加一个带钥匙孔的盒子

与 Subroutine_Hello 的区别：社区调查 cge7-193 服务器时找到一张叫 Subroutine_Hello 的地图，地板、门道、钥匙都和上述空间高度相似，明显互有关联；但它并非虚空最底部——地图上有一道可以坠落下去的巨大缺口，说明它处于另一层位置。

6.4 记忆（Memories）：虚空如何存储与访问

虚空以未知方式录制并存储玩家在各种 Source 引擎游戏中的事件，这些事件被称为记忆（memories）。访问记忆有两条路径：

  • 脚力偶遇：在第三次远征中步行探索时直接撞见（目前仅确认一例）
  • Type 7 demo + spray 交互 + 立方体入水（主要方式）

精确触发链：

  1. Type 7 demo 通常会反复播放铃声——它是判别器（discriminator）
  2. 当立方体被放入水中时，若在 Source 引擎游戏中放置了一张与某条已有记忆足够接近的 spray，原本的铃声会被三段连续音效取代
  3. 这三段音效就是对应记忆的访问密码
  4. 把立方体放在 Ordinance 地图的 A 按钮上，在控制台回放这三段音效，Type 7 demo 就会把玩家传送到对应的记忆

虚空存储的具体记忆：

记忆 详情
axlvote Anomidae 年轻的 Scout 自己在地图上跳，甚至能与现在的他对话，问他有没有麦克风、骂他"烦人的老东西"——这不只是录像，年轻自我有真实反应
Unknown Castle Map Anomidae 为朋友创建的城堡地图；2014 年 Eida 做 Spise 实验时也找到了这张地图。第二次访问时已被 Void Probe 实体攻击。该地图与歌曲《Breeze》的视频画面相似，Anomidae 二访时播放的正是《Breeze》的改编版，INTERLOPER F 结尾独白中也用了另一版改编

6.5 Final Transmission（最终传输）

INTERLOPER F 结尾，Skyghost 被摧毁后放出的最后信号：

  1. 一个使用 2005 年 FSKY 广告中人体模型的实体在虚空中坠落
  2. 数段 Type 5 风格的 demo 视频叠加其上
  3. 该实体最终落在一张未知地图上——一片广阔空间，反射质感的地面，远处有山丘
  4. 该地图位置只知在 d1_town_01 正下方，具体归属不明
  5. 人体模型穿透地板坠落的瞬间，一个灰色圆锥体出现并浮向天空
  6. 一只 Utah Teapot（犹他茶壶） 出现在天空，似乎将圆锥体击落回地面

这段传输留下的核心疑问：那张反射地板地图究竟在何处？它与 FSKY 广告中的人体模型、以及与 d1_town_01 涂鸦的关联是什么？——至今无解。

七、现状与核心未解谜团

根据 INTERLOPER F 的结尾，PROJECT SKYBOX 和 Anomidae 都宣称 INTERLOPER 调查已结束并被视为失败。但通过 FLASHLIGHT NUKE 攻击 Skyghost 并切断服务器连接后，Skyghost 的最终传输（Final Transmission） 显示了一个使用 2005 FSKY 广告中人体模型的实体坠入虚空，最终落在一张反射地板、远处有山丘的未知地图上——而那只 Utah Teapot 的出现，更像是某种更高层级的"系统"在对入侵者做出回应。
